# Design Properties

Yuru の各機能で満たしたい性質をカテゴリ別にまとめる。
ここに書くのは「**何を成立させたいか**」だけ。具体的な実装手段や調査結果は別 doc（`backlog-details/` 配下の spike / 設計 doc）に書く。

## Provider session と worktree の対応

- worktree を削除した時に、そこで作業したセッションの追跡が困難にならない（前提）
  - repo root で `claude --resume` して出るのが嬉しい
- resume 時に「前回と作業場所が違う云々」のメッセージが出ない（前提）
  - セッション作成時から worktree を移動しても問題にならない
- セッション作成時にエージェントが自分の作業場所を把握している
- ユーザーのメッセージとしてシステム都合のメッセージが差し込まれない
- セッション復帰（resume）時にエージェントは追加のコンテクストを与えられずに動作する
  - 前回の作業場所がそのまま引き継がれる
- provider によって定性的な挙動に差異がない（suggestion の精度など定量的な差異は OK）
