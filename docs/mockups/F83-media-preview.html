F83 — 音声・動画プレビュー

preview パネルで音声・動画を再生する。設計は F83-media-preview.md。 このページのプレイヤーは本物（<audio> / <video> の ネイティブコントロール。素材は F83-media/）なので、押すと実際に鳴る・動く。 メタ情報の長さと寸法も、本番と同じく要素から読んだ値を出している。

この mock で決めたいこと

  • プレイヤーは作らない。controls を付けるだけ。再生・シーク・音量・速度・全画面はブラウザのもの
  • diff は画像とまったく同じ枠。片側だけなら 1 面、両側あるなら Before / After の 2 カラム
  • 比べるのはメタ情報。画像が 1920 × 1080 · 2.4 MB を並べているのと同じ位置に、長さ（動画は寸法も）とサイズを並べる
  • 時間軸の共有・波形・A/B 切り替えは作らない

7音声コントロールの地の色

上のセクションはすべて B を当てている。::-webkit-media-controls-panel の background-color を差し替えるだけの 1 行で、触れるのは地の色・外枠・一部のボタンの有無まで。 タイムラインの線とつまみ、アイコンの色には CSS が届かないので、そこまで合わせたいなら自前のプレイヤーになる。

theme-loop.wav assets/audio
A. 既定（何もしない）
B. 地の色だけ寄せる — panel { background-color: var(--bg-panel) }
C. さらに角丸を落として枠線 — enclosure { border-radius; border }
D. 音量を消す — mute-button / volume-slider { display: none }（⋮ は消えない）
