F82 + F77 — ブックマークの compose 欄

Bookmarks タブを「上＝スクロールする一覧、下＝常設の 1 行入力」に変える。 F82 はその欄に URL を入れて Enter、F77 はその欄に画像を貼り付けて Enter。 入口を 1 か所にまとめたので、「+」ボタンも、ペイン全体で貼り付けを拾う仕組みも要らない。 下に置くのは、追加したものが一覧の末尾に増えるから（並び替えを将来入れても、追加が末尾に入ることは変わらない）。

1. 通常時 — リンクと画像が同じ一覧に並ぶ

一覧はスクロールし、compose 欄は下に固定される。画像行はサムネイル（36×36）+ タイトル 1 行で、 file://… のメタ行は出さない。サムネイルは <img src={bookmark.url}> で直接読む （実ファイルなので取得用の IPC は要らない）。一番下の画像は貼り付け直後 — 追加は常に末尾。

クリックしたときに開く先は種類で変わる。リンクは今まで通り既定ブラウザ、画像は 既存のプレビュー（ファイルをプレビューで開くのと同じ）。プレビューは worktree 外の 絶対パスを既に開けるので、画像用の「開く」IPC は足さない。既定タイトルは Pasted image で、 画像は GitHub URL ではないので鉛筆（リネーム）はリンクと同じ条件でそのまま出る。

2. compose 欄の 3 状態

空（既定）

placeholder で受け取れるものを 2 つとも示す。

URL を入力・貼り付け

Enter で addBookmark。検証・重複判定・title 解決は既存の IPC のまま。 成功したときだけ空にするので、http/https 以外で弾かれても入力は残って直せる。 Escape は入力を空にするだけ（閉じるものが無い）。

画像を貼り付けた状態

Pasted image

テキスト入力は添付チップに置き換わる（1 件のブックマークはリンクか画像のどちらか）。 Enter で addImageBookmark、Escape か × で破棄。 貼った瞬間に登録しないのは、チャットの添付と同じく確定を 1 手挟むため。

3. 0 件のとき

No bookmarks

現状の実装は 0 件のとき EmptyState だけを返すので、この早期 return をやめる。 最初の 1 件を入れる場所が常に見えている状態にする。

4. 検討中: 添付を入力欄の「上」に積む案

実装済みの案 A は、画像を貼ると入力欄が添付チップに置き換わる。input が居なくなるのでフォーカスが外れ、 Enter を受けるために compose 欄を tabIndex={-1} にして明示的にフォーカスを移している。 案 B はチップを入力欄の上に積むので input が残り、その仕掛けが全部要らなくなる。 代わりに入力欄が生きたままになるので、そこに打った文字をどう扱うかを決める必要がある。

案 A（実装済み）— 置き換える

Pasted image

貼り付けている間は文字を打てない。ブックマークはリンクか画像のどちらか、という切り分けが 見た目に出る。タイトルは登録後に鉛筆でリネームする。高さは 1 行のまま変わらない。

案 B — 上に積む（貼った直後）

Pasted image

チップが 1 段増えて compose 欄が 2 行になり、そのぶん一覧が上に詰まる。カーソルは入力欄に残るので、 貼った直後からそのまま打てる・Enter も効く。placeholder は役割が変わる（URL → タイトル）。

案 B — タイトルを打った状態

Pasted image

入力欄が生きている以上、打った文字は無視できない。素直なのは「添付中に打った文字はその画像の タイトルになる」。チャットのキャプションと同じで、以前スコープ外にした案がここで戻ってくる。

案 B を実寸で見る（貼り付け中）

Pasted image

貼っている間だけ下が 2 段になり、一覧の見える範囲が 1 行分ぶん縮む。Enter で登録すると チップが消えて 1 行に戻り、一覧は元の高さに戻る。

案 B だと登録結果が変わる

Enter を押した後の行

上は案 B でタイトルを打って登録した行。下は打たずに Enter した行（案 A と同じ Pasted image）。 案 B は「貼る → 名前を打つ → Enter」が 1 続きの操作になり、案 A の「貼る → Enter → 鉛筆 → 打つ → Enter」より短い。

迷いどころ

案 B は入力欄の意味が状態で変わる。添付が無ければ URL、あればタイトル。 チップが出ているかどうかで見分けられるとはいえ、同じ 1 つの欄が 2 つの意味を持つ。

間違えたときの挙動も変わる。案 A は URL を打った状態で画像を貼ると打った内容が隠れる （破棄すれば戻る）。案 B は打った URL がそのままタイトルとして登録される。

高さも変わる。compose 欄が 1 行 ↔ 2 行で伸縮するので、貼るたびに一覧が上下する。
