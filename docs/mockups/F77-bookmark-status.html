1. 採用案（幅 375px = Explorer パネルの既定幅）

Bookmarks タブ

Bookmarks

タイトルは 2 行まで折り返し、バッジは 2 行目の先頭。行の縦パディングは 10px（現状 6px）で、行の境がタイトルの折り返しに紛れないようにする。行の高さはタイトル 1 行で約 56px、2 行で約 72px。

バッジ 7 種

issue / open Open #482 .github-badge.issue.open issue / closed Closed #367 .github-badge.issue.closed pr / open Open #491 .github-badge.pr.open pr / open + approved Approved #491 .github-badge.pr.open（色は同じ、語だけ変わる） pr / draft Draft #503 .github-badge.pr.draft pr / merged Merged #10218 .github-badge.pr.merged pr / closed Closed #455 .github-badge.pr.closed

色は「その仕事がどうなったか」に対応する。 緑 = まだ生きている（open issue / open PR、approved も同じ緑）、 灰 = まだ本番向けではない（draft PR）、 紫 = 片付いた（merged PR / closed issue）、 赤 = 打ち切られた（closed PR）。 新しい色は 1 つも増やさない。closed issue は merged の紫を共有する。 アイコンは種別だけを表し、状態では変えない（issue = CircleDot、PR = GitPullRequest）。

2. 却下案

タイトル 1 行 / パディング 6px

Bookmarks

タイトルが 1 行 … 切り、縦パディング 6px。2 行になった行同士がくっついて見え、長いタイトルは何の件か読めない。

バッジ専用の行を作る

Bookmarks

バッジだけの行を最初に足した案。タイトルは 1 行のままで何も改善しないうえ、色つきのピルが行の頭に来るとそこが区切りに見えて、どこで 1 件が終わるのか読めなくなる。

タイトル行の右端に置く

Bookmarks

RepoList / ターミナルバーと同じ末尾配置。(1) バッジが後から届いた瞬間にタイトルが縮んで 折り返し位置が動く。(2) 削除ボタン (×) の真横に色つきの丸ピルが並び、ボタンの仲間に見える。(3) アイコンが右端でそろわないので、状態を縦に追えない。
