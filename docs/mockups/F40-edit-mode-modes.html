F40 Edit Mode — モード切替ヘッダ

ファイル表示を 閲覧 / 編集 / プレビュー でファイルごとに切り替える。そのヘッダ部分の検討用モックアップ。

⚠ このモックの見方

  • 検討対象は ヘッダ（ファイル名・ディレクトリ・モード切替）だけ。
  • 本体（コード / diff）はダミー。ガターの色・シンタックスの配色・レイアウトなどは、それっぽく置いただけなので実装の参考にしないこと。diff 本体の見た目は既存の閲覧モードに従う。
  • プレビューモードは未実装（F40 スコープ外）。一番左に描いてあるのは将来の置き場所のイメージで、型にもまだ加えない。現状の実装は 閲覧 | 編集 の 2 モードのみ。モードの型は 3 つ以上に拡張できる列挙として作るが、今は 2 つだけ持つ（YAGNI）。

■ ヘッダ仕様（固定）

  • ファイル名を主役にして左へ。uppercase にしない。省略もしない。
  • ディレクトリはファイル名の真横。質感は Changes と揃える（subtle・mono・小さめ）。あふれたら後ろ省略（標準 ellipsis）、全パスはホバーで title に出す。
  • モード切替はアイコンのセグメント（コンパクト）。モノレポの長いパスと両立。
  • 並びは プレビュー → 閲覧 → 編集（左ほど完成形・デフォルト優先）。プレビューは差分もレンダリングで見せられるので、存在すれば一番左でデフォルトにできる（プレビューの実装自体は F40 スコープ外）。
  • 右クラスタの並び：[モードアイコン] [+追加/−削除] [×]。
  • バイナリ（画像含む）は編集アイコンを disabled にするだけ。
