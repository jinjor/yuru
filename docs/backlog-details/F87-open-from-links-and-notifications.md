# F87 `yuru://` のリンクと Yuru 自身の通知から、Yuru の特定の場所を開く

## 背景

- エージェント（Claude Code など）から、`osascript` の `display notification` で macOS の通知を出している。クリックすると通知を出したアプリ（スクリプトエディタ）が開くだけで、開く先を指定できない
- macOS の通知のクリックは、通知を出したアプリにしか届かない。通知に「クリックでこの URL を開く」という汎用の欄はない
- Yuru には URL スキームも、開けるファイルの種類も登録されていないので、Slack のメッセージや HTML のリンクから Yuru の特定の場所を開く手段もない

## やること

1. URL スキーム `yuru://open?...` を登録する。受け取ったら Yuru を前に出し、指定された場所を開く。開ける対象（ファイルのパス、worktree など）とパラメータの形は実装するときに決める
2. `yuru notify --title <タイトル> --message <本文> [--open <yuru:// の URL>]` を足す。CLI から動いている Yuru に頼み（`yuru ping` が確かめているのと同じ、アプリとのやりとり）、Yuru 自身の名前で macOS の通知を出す。クリックされたら、1 と同じ処理で `--open` の場所を開く
3. Yuru が動いていないときは、`yuru notify` は失敗の終了コードを返す。呼び出し側が、ほかの方法の通知に切り替えられるようにする

## 使い道

- エージェントの確認事項の通知をクリックして、その内容を出している HTML を Yuru で開く
- Slack や HTML に貼った `yuru://` のリンクから、Yuru で直接開く
