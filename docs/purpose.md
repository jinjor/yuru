# Purpose

Last updated: 2026-05-16

そもそも Yuru がなぜ必要かを整理する

## What's Yuru

並列作業をストレスなく行うための AI コーディングに特化したエディタ。
複数の AI エージェントをシームレスに統合する。

## What problems will Yuru solve?

既存エディタの課題

- セッションと worktree の紐付けが困難
  - セッションがどの worktree で作業しているのか分かりにくい
  - 逆に worktree がどのセッションの作業場所なのか分かりにくい
- 既存エディタ（VSCode 等）が使いにくい
  - セッションと worktree が分離している
  - 複数の worktree のファイルが同じ画面上に並んで混乱する
  - 複数の worktree を跨いで検索してしまい混乱する
  - レイアウトを自分で工夫して使うしかない
- AI コーディング用の GUI が使いにくい
  - ベンダー固有で複数のエージェントを跨いで使用できない
  - セッションファーストな UI で作業場所が分かりにくい
  - 使用済みのゴミ worktree が可視化されない
  - worktree を作らずに作業したり worktree を跨いで作業する柔軟性も欲しい
